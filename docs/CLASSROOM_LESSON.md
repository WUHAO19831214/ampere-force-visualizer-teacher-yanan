# 教师端课堂教学方案

## 1. 课题建议

“从多源实验证据到安培力空间方向关系”。建议 1 课时，也可拆为实验采集和规律归纳两课时。

## 2. 教学目标

- 理解 I、B、F 的空间方向及坐标表示；
- 能区分传感器数值、视觉方向和程序模型；
- 能用左手定则和叉乘解释观察结果；
- 形成对数字工具证据边界的认识。

## 3. 课堂结构

### 导入

展示原 DIS 软件、摄像头实验画面和三维图，让学生判断三者分别提供什么证据。

### 实验采集

教师展示屏幕授权、ROI 和 OCR 调试，强调数值来自传感器但由 OCR 转录。学生记录读数和方向。

### 方向识别

利用 N/S 标记显示 B 方向，讨论视觉识别可能受光照和遮挡影响。

### 模型生成

暂停一帧，展示 Fy、Fz、合力、安培力和磁场方向。比较三维图与真实装置。

### 学生探究

把 I、α、β 提供给学生端，学生独立旋转、归纳并提交解释。

### 证据复核

回到教师端关键快照和原始画面，讨论“观测”“识别”“计算”之间的关系。

## 4. 建议提问

- OCR 数值为什么不能直接等同于传感器真值？
- B 方向来自什么证据？
- 三维箭头是拍摄到的还是计算出的？
- 若学生输入的 F 不符合左手定则，学生端会不会自动纠正？
- 视觉角度和物理空间角度之间需要什么标定？

## 5. 课堂产出

- 一张来源分层表；
- 至少四组 I、B、F 方向记录；
- 一段左手定则/叉乘解释；
- 一份误差与局限反思。
