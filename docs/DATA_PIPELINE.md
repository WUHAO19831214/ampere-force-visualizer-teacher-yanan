# 数据管线与来源分层

## 1. 来源分类

| 数据 | 直接来源 | 在本程序中的性质 |
| --- | --- | --- |
| 力传感器读数 | DIS 传感器，经原软件显示 | 实测量的 OCR 转录值，不是直接硬件读取 |
| rawText / confidence | Tesseract OCR | 识别过程元数据 |
| N、S 坐标与 B 方向 | 摄像头图像、颜色标记 | 视觉识别结果 |
| mock 数值/视觉样本 | 程序生成 | 调试数据，不是实验数据 |
| 合力、夹角、垂直判定 | 向量计算 | 程序派生量 |
| 三维箭头、磁感线 | Three.js | 程序建模图形 |

## 2. 屏幕数据管线

```text
getDisplayMedia 授权流
  -> 视频帧
  -> 归一化 ocrRoi 裁剪
  -> 图像预处理
  -> NumberRecognizer
  -> 数字提取和格式化
  -> 物理范围/跳变/平滑过滤
  -> useExperimentDataStore
  -> 实时显示、三维模型、CSV
```

每个 `PhysicsSample` 带有通道、符号、单位、时间戳、方法、rawText、confidence、durationMs 和 warning 等字段，便于追溯。

## 3. 视觉数据管线

```text
getUserMedia 授权流
  -> 摄像头帧
  -> 视觉 ROI
  -> 分析器或磁极标记检测
  -> VisionSample / MagneticFieldDetectionResult
  -> Overlay、实时面板、三维磁场方向、CSV
```

当前 N/S 方向使用红、蓝颜色阈值和连通区域；其他视觉分析器中部分仍为占位或 mock，不能统称为已完成真实视觉测量。

## 4. 过滤与连续失败

- 可按 `minValue`、`maxValue` 拒绝物理范围外值。
- 可按 `maxDeltaPerSample` 检测异常跳变。
- 跳变值需连续两次接近才接受。
- 平滑采用最近最多 5 个值的中位数。
- 识别失败时保留上一次有效值；连续 3 次失败后产生明确 warning。

这些规则提高课堂稳定性，但也会引入延迟和保留效应，研究报告应记录配置。

## 5. 三维模型输入

教师端三维模块从正式数据流读取 Fy/Fz（兼容旧通道 F2/F3），根据统一比例尺绘制分量、合力和可选安培力。摄像头方向被映射到课堂 y-z 平面。图形长度可能为可见性做最小放大，但数值读数不因此改变。

## 6. 时间与同步限制

屏幕 OCR、摄像头和渲染拥有各自频率，当前没有硬件级统一时钟或精确帧同步。跨来源比较应使用时间戳并允许合理时间窗，不应把同一页面时刻等同于严格同步采样。
