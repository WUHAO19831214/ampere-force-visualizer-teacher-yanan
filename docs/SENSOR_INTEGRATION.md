# DIS 与传感器接入说明

## 1. 接入方式

当前教师端没有连接朗威 DIS 的 SDK、串口、USB 协议或内部数据库。实际链路是：

```text
力传感器 -> DIS 硬件/原软件 -> 屏幕显示 -> 浏览器捕获 -> OCR
```

因此准确表述是“读取原软件屏幕上显示的传感器数值”，不是“直接读取 DIS 内部数据”。

## 2. 为什么采用屏幕感知式桥接

- 原软件可能封闭或缺少稳定导出接口；
- 教师仍可使用熟悉的实验软件；
- 浏览器标准 API 跨厂商、跨软件界面复用；
- 原始显示仍可见，便于人工核对和课堂解释。

代价是 OCR 误差、窗口布局依赖、权限交互和采样延迟。

## 3. 力数据含义

教师端默认通道面向力读数，单位由 ROI 配置指定，常用为 N。仓库中的三维模块读取 Fy/Fz（兼容旧 F2/F3）并形成传感器合力；安培力可按实验约定显示为传感器合力的反向。

研究中应保存：传感器型号、量程、零点、采样设置、原软件版本、通道映射、单位和 OCR 配置。

## 4. 校准建议

1. 传感器空载调零。
2. 用已知载荷检查原软件显示。
3. 人工读取与 OCR 同时记录至少 20 个覆盖量程的样本。
4. 估计 OCR 转录误差与传感器本身误差，二者分开报告。
5. 检查符号方向，确认正负值与课堂坐标一致。

## 5. 兼容其他设备

只要设备软件能稳定显示数字，理论上可配置 ROI 进行桥接；但每种软件都需要重新验证字体、颜色、刷新方式和单位。仓库目前没有提供厂商兼容性认证。
