# 教师端课堂工作流

## 1. 课前准备

1. 连接并校准 DIS 力传感器，确认原实验软件能稳定显示目标通道。
2. 在导体、磁体或标记物上布置课堂可识别的方向标记。
3. 启动教师端，检查浏览器的屏幕捕获、摄像头和下载权限。
4. 选择实验软件窗口，校准屏幕 `displayRoi` 与 `ocrRoi`。
5. 选择摄像头设备，校准视觉 ROI、红色 N 极和蓝色 S 极阈值。
6. 用已知读数和已知方向完成一轮基准检查。

## 2. 课堂采集流程

```text
DIS 传感器
  -> 原实验软件显示
  -> 浏览器授权屏幕捕获
  -> OCR ROI
  -> 数值过滤与存储

摄像头实验画面
  -> 视觉 ROI / N-S 标记识别
  -> B 方向

数值 + 方向 + 坐标约定
  -> Three.js 三维图示
  -> 角度、合力与关键快照
```

## 3. 建议操作顺序

1. 点击“开始捕获屏幕”，明确选择 DIS 软件窗口或整个屏幕。
2. 调整绿色显示 ROI，使通道身份清楚。
3. 调整黄色 OCR ROI，只保留数字和必要符号。
4. 用“测试当前 ROI OCR”检查 rawText、value、confidence 和预处理图。
5. 打开摄像头并选择正确设备。
6. 检查 N、S 标记及 `B: N → S` 方向。
7. 观察右侧实时数据，再进入三维图示。
8. 在关键现象处暂停、截图或开启自动截图。
9. 课后导出 CSV，并保存必要的原始截图与课堂记录。

## 4. 教师与学生端配合

- 教师端负责呈现实验来源、校准过程和证据链。
- 学生端负责手动输入一组 I、α、β，旋转观察并归纳规律。
- 当前两端没有实时网络同步；教师通过课堂指令、投屏或记录表传递数据。
- 学生端输入不是教师端自动下发，也不是实测数据的数据库副本。

## 5. 异常处置

| 现象 | 建议处理 |
| --- | --- |
| OCR 无值 | 检查窗口授权、ROI、预处理和 Tesseract 状态 |
| 小数点丢失 | 收紧 ROI、提高图像尺寸、切换预处理模式 |
| 数值突变 | 检查 `maxDeltaPerSample` 和连续稳定接受机制 |
| N/S 丢失 | 检查光照、颜色阈值、遮挡和最小面积 |
| 三维箭头太短 | 检查比例尺；可见性放大不等于数值被修改 |
| 浏览器权限失效 | 重新授权；网页不能绕过用户许可 |

## 6. 证据保存

- 摄像头“截取当前画面”下载 PNG；
- 三维模块关键快照保存在当前页面状态中，可手动或自动生成；
- 屏幕数据和视觉数据分别导出 CSV；
- 页面内快照并非长期数据库，刷新或关闭前应另行保存需要的证据。
