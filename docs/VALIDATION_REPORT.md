# 验证报告与证据状态

## 1. 报告范围

本文档区分代码审查可确认的能力与仍需实验数据支持的结论。

## 2. 代码可确认

- 使用 `getDisplayMedia`，必须由用户授权屏幕或窗口。
- 使用 `getUserMedia` 获取摄像头。
- ROI 使用归一化矩形，display ROI 与 OCR ROI 分离。
- Tesseract 白名单为数字、小数点和负号。
- OCR 失败不会自动替换为 mock 正式数据。
- 支持范围过滤、跳变过滤、最多 5 点中位数平滑和连续失败 warning。
- 屏幕与视觉数据有独立 CSV 字段。
- N/S 标记方向按 N 到 S 生成视觉 B 方向。
- 三维图和关键快照由程序生成，快照可包含数值与角度元数据。

## 3. 尚需实证

- 不同 DIS 软件版本和显示器上的 OCR 准确率；
- 真实课堂光照下 N/S 识别准确率；
- 屏幕、摄像头与传感器时间同步误差；
- 长时间运行稳定性；
- 不同浏览器和设备兼容性；
- 对学习效果的影响。

## 4. 建议测试矩阵

| 类别 | 样本/条件 | 指标 |
| --- | --- | --- |
| OCR 静态 | 人工标注截图 ≥ 100 | 完全正确率、数值误差 |
| OCR 连续 | 多个稳定/跳变序列 | 丢帧率、延迟、误拒绝率 |
| 视觉方向 | 多光照、多角度、遮挡 | N/S 检出率、方向角误差 |
| 数据管线 | 屏幕+摄像头并行 30 分钟 | FPS、OCR Hz、内存、warning |
| 三维模型 | 已知向量用例 | 分量、合力、夹角正确性 |
| 课堂 | 多设备小组使用 | 完成时间、故障率、学习证据 |
